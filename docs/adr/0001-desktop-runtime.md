# ADR-0001：桌面运行时选型

- 状态: Proposed
- 日期: 2026-11-18
- 决策者: Timbre 维护者
- 取代: 无
- 关联: `.specs/tasks/desktop-runtime-baseline.md`（待建）、`docs/research/axiom-page-migration.md`

## 背景

Timbre 是本地优先的桌面运营平台，需要一个承载 UI 与 Agent 运行时宿主的桌面运行时。当前两个候选：

- **Tauri 2 + React**：与 axiom 同栈，生态成熟，页面层可直接复用 React 组件与既有代码路径；代价是 webview 的内存与启动开销。
- **MyGo（Go + GPU 自绘）**：单个 Go 二进制，启动即时、内存低；代价是生态年轻（v0.x，官方明确「允许破坏性变更」），且 axiom 的宿主层需重写或经实验性的原生模块挂载。

axiom 页面替换可行性调研（`docs/research/axiom-page-migration.md`，2026-11-18）给出的关键事实：

1. axiom 页面层 27,702 行生产代码，与 React 生命周期无强耦合的部分可按 MyGo 的 `ui` 模型重写；
2. 迁移的重活集中在**设计画布**（15,457 行，依赖 SVG + Canvas 2D 双轨渲染与 PNG 导出，MyGo 无对应组件）与**运行时宿主**（59,800 行 Rust 承载文件授权登记、密钥表、网络策略、审批流、PTY、CDP、SSH、SQLite）；
3. MyGo 侧 CDP 浏览器操控与 SSH 无等价物；Rust 代码复用只能走标注为实验性的原生模块；
4. axiom 的宿主面远大于 Timbre MVP 所需（Timbre 不需要设计画布、SSH、CDP 浏览器）。

因此真正决定选型的不是「axiom 能不能整体搬到 MyGo」，而是「Timbre 需要多少宿主能力、愿意为哪种形态付代价」。

## 候选方案

| 方案 | 要点 | 代价 |
|---|---|---|
| A. Tauri 2 + React | 沿用 axiom 栈；Rust 宿主 + TS 前端；webview 承载 UI | webview 内存与启动开销；前端需 Node 工具链；Rust 与 TS 双语言 |
| B. MyGo 全原生（Go + `ui`） | 单 Go 二进制；原生 UI 自绘；Go 单语言覆盖宿主与前端 | axiom 宿主面需重写；MyGo v0.x 允许破坏性变更；设计画布等自建组件成本高；生态与文档密度低于 Tauri |
| C. 混合：MyGo 原生外壳 + webview 承载复杂页面 | MyGo 支持一窗两态混排（原生 UI 与 web 页面共存） | 两套渲染路径与两套心智模型；边界不清；收益不足 |

## 决策

**选 A（Tauri 2 + React）作为 Timbre 的桌面运行时。**

理由：Timbre 的核心资产是**本地优先的特权边界与审批流**，不是像素级的启动速度与内存占用。axiom 已用 59,800 行 Rust 把这层边界（文件授权登记、密钥表、网络策略、逐次审批、会话持久化）实现并被自身能力矩阵固化为可测试的不变量。选 Tauri 2 意味着这层边界可直接沿用其形态与经验，代价可控；选 MyGo 则要求在 v0.x 框架上重写这层边界，且「实验性原生模块」不能作为长期依赖锚点。

设计画布这一具体重活同时得到豁免：Timbre MVP 不需要它（见调研第 6.5 条）。

## 后果

- 变好的部分：
  - 特权宿主与本地优先边界可沿用 axiom 的形态与已验证实现，避免在早期重造；
  - 前端生态成熟，腔调 skill 的产物预览（Markdown、diff、封面 brief）可直接用现成组件实现；
  - 与 axiom 共享工程习惯（规格先行、ADR、变更记录），协作成本低。
- 变差或必须承受的部分：
  - 接受 webview 的内存与启动开销；本次决策未做实测，量化收益悬空；
  - 工具链为 Rust + Node 双语言；
  - 与 axiom 栈耦合，日后若要切 MyGo，需重做宿主层（调研已给出代价清单）。
- 对本地优先边界的影响：
  - **无新增云端依赖。** 运行时选型不引入任何远端服务；模型调用沿用 axiom 的 provider 机制，属用户自有凭据、按既有 Task Spec 声明与本地回退执行。
  - 密钥仍只写本地存储，不随运行时选型改变存放位置。

## 未决问题

- MyGo v0.x 的破坏性变更节奏是否会在若干年内使上述决定显著变贵——需要一次基于实测数据的复评（启动耗时、内存、宿主重写工时），本次决策未覆盖。
- Agent 运行时语言与形态（Rust 宿主内的循环，还是独立进程）尚未决策，另立 ADR。
- MVP 是否需要内嵌浏览器预览、多窗口、终端面板，直接影响上述运行时能力盘点，需在 0.1 规格收敛时确认。

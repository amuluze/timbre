## 增删平台规则

- 增平台：先在本文件写入一行（腔调要点 + 依据状态标「设计意向」），再建对应 Domain Spec 条目，之后才进入 Task Spec 与实现
- 删平台：不删除，把「依据状态」改为「已移除（YYYY-MM-DD，原因）」，并在 `CHANGELOG.md` 对应版本记录一行
- 修订要点：「依据状态」从「设计意向」升级为「已验证」时，必须注明验证来源（平台运营者、数据表现或平台公开规则）
